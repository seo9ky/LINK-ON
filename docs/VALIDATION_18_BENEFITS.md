# 18개 혜택 최종 점검 — 2026-10-30

## 범위

최종 Figma 프로토타입과 웹의 6개 업종·18개 가맹점을 점검했다. 초안, 상세기획 슬라이드, 로고, 색상, 아이콘 및 기존 레이아웃은 유지했다.

## 화면

- Figma 목록의 아이콘 44×44, 텍스트와의 간격 12px, 액션 영역 96px를 확인했다.
- 웹 375×812에서 아이콘 40×40, 440×956에서 44×44를 확인했다. 상세 아이콘은 64×64이며 원본 비율을 유지한다.
- 18개 목록의 상호·금액·조건과 상세 화면에서 가로 넘침 및 버튼 겹침을 발견하지 않았다. 작은 화면의 업종 선택 줄바꿈도 확인했다.
- 웹 콘솔 오류·경고 없음. 디자인 수정이 필요한 결함은 발견되지 않아 프론트엔드 시각 스타일은 변경하지 않았다.

## 웹 실제 클릭 검증

- 18개 각각 직접 LINK → 완료 → 상세 → 해제 확인 → 해제 → 재연결 가능 상태를 확인했다.
- 시연 도구에서 전체 업종과 테스트 한도 18을 선택해 모든 혜택을 자동 연결하고, 18개 각각 상세 → 제외 확인 → 제외 완료 → 메인 개수 감소를 확인했다. 테스트 한도는 운영 정책이 아니다.
- 전부 제외한 뒤 LINK ON을 껐다 켜도 동일 행사가 자동 복구되지 않는 것을 확인했다.
- 자동 제외한 배스킨라빈스 혜택을 직접 연결할 수 있으며 완료 상태로 표시되는 것을 확인했다.

## Figma 보완

- 상세 화면 복귀를 미동의 / OFF / ON·자동 혜택 있음 / ON·자동 혜택 없음으로 분리했다. 여러 분기가 누락되던 조건을 각각 독립적인 조건식으로 저장했다.
- 메인 및 관리 화면 분기가 기존 두 가맹점만 보지 않고 전체 자동 연결 상태를 반영하도록 정리했다.
- OFF 상태에서 관심 업종 저장 후 OFF 메인으로 돌아오도록 수정했다.
- 자동 연결 상세에는 연결 이유를, 직접 연결 상세에는 이용방법을 표시한다. 확인 버튼도 자동 연결은 '혜택 제외', 직접 연결은 'LINK 해제'로 구분한다.
- 상세 화면에서 연결 또는 제외 직후에도 안내 문구가 현재 상태에 맞게 갱신된다.
- 재선정 시 기존 자동 연결 업종을 반영해 업종별 배분 상태가 초기화되지 않도록 했다.

Figma 검증은 저장된 연결 대상·조건식·변수의 검사와 상태 시뮬레이션으로 수행했다. 18개 상세의 4가지 복귀 상태, 총 72개 조건을 통과했다. Figma 실행 화면의 전체 클릭 검증과 웹 실제 클릭 검증은 구분한다.

## 재발 방지

18개 자동 혜택의 개별 제외, OFF·ON 후 제외 유지, 직접 재연결·해제의 독립성을 자동 검사에 추가했다. 웹 로직은 기존 동작이 맞아 변경하지 않았다.
