# 브랜드 이미지 출처

이번에 추가한 15개 PNG는 사용자가 이 프로젝트 제작을 위해 직접 첨부한 원본이다. 파일 내용이나 로고 비율은 변경하지 않고 Figma의 FIT 및 웹의 object-fit: contain으로 배치한다.

공차, 배스킨라빈스, KREAM, 지그재그, CU, 이마트, BBQ, 도미노피자, 배달의민족, 쿠팡, SSG.COM, 11번가, 올리브영, 아이허브, 닥터나우.

스타벅스·SSF SHOP·GS25는 기존 사용자 제공 자산을 유지한다. 상표와 이미지의 권리는 각 권리자에게 있으며, 시연 화면의 등장은 실제 제휴 또는 혜택 제공의 확인을 의미하지 않는다.
