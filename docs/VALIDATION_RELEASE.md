# 웹·문서·QR 점검 — 2026-10-30

## 변경 범위

서비스 소개 중심 README, 개발 안내 분리, 자료 출처 통합, 업종 필터와 안내 문구·가독성 개선, QR PNG 추가. 기존 로고 파일·서비스 정책·결제 판정·버튼 이동 경로는 유지했다. Figma와 보관된 PDF는 이번 변경에 포함하지 않았다.

## 로컬 결과

| 검사 | 결과 |
| --- | --- |
| TypeScript·Vite 빌드 | 통과 |
| 상태·정책 단위 검사 | 22개 통과 |

| 375px·440px 화면 | 주요 화면 이미지 로드·가로 넘침 검사 통과, 시작·상세 화면 육안 확인 |
| QR 판독 | 1200·600·300px, 컬러·흑백 6개 조합 모두 동일 주소 판독 |

브라우저 검사는 직접 연결·해제 취소/확인·재연결, 새로고침, 자동 LINK와 직접 LINK의 독립성, 개별 제외 후 재활성화, 관심 업종 저장/취소, 다음 행사 선정, 결제 후 해제·전표 접수, 결과 보존, 확인창 포커스·뒤로가기, 초기화를 포함한다.

업종 필터 검사를 추가해 전체 18개 → 선택 업종 3개 → 연결·상세 왕복 → 해제 → 전체 복귀를 확인했다. 필터가 연결 개수나 관심 업종 설정을 바꾸지 않는지 점검했다.

기본 Playwright 브라우저는 설치되어 있지 않아 첫 실행이 중단됐다. 설치된 Chrome 경로를 지정한 뒤 실행했고, 확인창과 본문에 같은 이름의 버튼이 있는 기존 테스트는 확인창 안의 버튼을 지정하도록 수정했다. 앱의 이동 흐름은 변경하지 않았다.

## QR

- 파일: `docs/assets/LINK-ON-QR.png`, 1200×1600 PNG
- 주소: `https://link-on.kro.kr/`
- 기존 벡터 로고·Noto Sans KR·LINK 컬러 사용
- QR 위 장식 없음, 4모듈 흰 여백, 오류 정정 H
- 원본·축소·흑백 파일을 ZXing으로 해독해 주소 일치 확인

실물 인쇄물과 휴대폰 카메라의 인식률까지 검증한 결과는 아니다. 배포 커밋별 Preview·Production 결과는 해당 PR의 Vercel 검사와 운영 사이트 확인 결과를 함께 본다.

이전 시점의 검사 기록은 `VALIDATION_v0.2.md`, `VALIDATION_18_BENEFITS.md`에 보존한다.


## 첫 방문·결제 체험 개선 검증 — 2026-10-30

첫 화면의 정보 순서, 상세 조건·결과 문구, 본문 크기와 여백을 조정했다. 폰 안에서 가맹점·금액 선택과 개별 결제 확인을 진행할 수 있게 했으며 기존 PAY·SETTLE 판정을 재사용한다. 기존 로고·색상·정책과 PC 휴대폰 비율은 유지했다.

- 빌드 통과, 정책 단위 검사 22개 및 브라우저 검사 18개 통과.
- 마지막 간격·스크롤 위치 조정 후 모바일 넘침, QR 첫 방문 체험, 최소 금액 미충족·재시도, PC 원본 크기 전환 4개 검사를 재실행해 통과.
- 375×812에서 첫 화면·관심 업종·자동 연결·결제 체험·확인 중·적용 결과·상세 조건을 직접 확인했다. 440px 가로 넘침과 이미지 로드는 기존 브라우저 검사에 포함한다.
- QR 주소는 변경하지 않았다. 실제 휴대폰 카메라 촬영과 iOS Safari 실기기 검증은 수행하지 않았다.

Preview와 운영 배포는 해당 변경 PR의 배포 상태와 운영 주소에서 확인한다.
