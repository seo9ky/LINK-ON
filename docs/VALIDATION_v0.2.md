# v0.2 검증 기록

검증일: 2026-10-30. 기획 PDF는 기존 스냅샷을 유지했다.

## 실행한 검사

- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- Node 상태·결제 테스트 14개 통과: 동의, 적합성·한도, 관심 업종 변경, 행사별 제외/만료, ON/OFF, 직접 연결/해제, 유효성 검사, 예산/오류, 결제 시점 판정, 중복 이용 방지, 받은 혜택 보존, 이전 상태 복원.
- Playwright 테스트 11개가 검색·등록됨. 독립 자동 브라우저 실행은 기본 브라우저 미설치 및 설치된 Edge 실행 종료로 테스트 본문에 진입하지 못함. 전체 E2E 통과로 기록하지 않는다.
- 연결된 인앱 브라우저에서 DOM 기반 버튼 동작을 검증했다. 사용자의 마우스/네이티브 앱을 조작하지 않았다.

## 브라우저에서 확인한 주요 흐름

1. 초기화 → 필수 동의 → 관심 업종 저장 → 맞춤 혜택 2개 연결.
2. 스타벅스 시연 결제 6,500원 → 확인 중 → 전표 접수 → 자동 LINK 할인 1,000원.
3. GS25 직접 연결 → 시연 결제 6,500원 → 상세에서 해제 → 전표 접수 → 직접 LINK 할인 1,000원 유지.
4. GS25 해제 후 새 결제 → 전표 접수 → 미적용과 연결 전 결제 사유. 합계는 2,000원으로 유지.
5. 스타벅스 11월 행사 제외 → OFF/ON → 같은 행사 자동 재연결 없음.
6. 시연 날짜를 12월 1일로 변경 → 11월 연결 만료 → 스타벅스·SSF SHOP 12월 행사 연결. 이전 받은 금액 유지.
7. 이미 이용한 해제 행사는 이용 완료 상태로 표시하여 재연결 차단.
8. 375px 너비에서 메인 화면의 문구·배치 확인, 가로 넘침 및 손상 이미지 없음.

## 범위

실제 금융 API, 추천 모델, 회원 인증, 서버 동의 이력, 취소·환불·전표 정정은 구현하지 않았다. 도구의 기본 한도와 선정 점수는 시연 가정이다. 전 화면·전 조합의 자동 브라우저 검사가 완료된 것은 아니다.
